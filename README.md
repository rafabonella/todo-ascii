# Lista de Tarefas

Aplicação web simples para organizar tarefas do dia a dia: o usuário adiciona tarefas, marca como concluídas e acompanha quantas ainda estão pendentes. Projeto de nivelamento da Diretoria de Projetos da ASCII, seguindo o ASCII Playbook.

## Stack

- HTML5
- CSS3
- JavaScript (puro, sem frameworks)

> Esta é a primeira etapa do projeto. A stack oficial do Guia de Engenharia (React, TypeScript e Vite) será adotada nas próximas etapas.

## Como rodar

Não é necessário instalar nada.

1. Clone o repositório:
   ```bash
   git clone git@github.com:SEU-USUARIO/todo-ascii.git
   ```
2. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server do VS Code).

## Funcionalidades

- Adicionar tarefas pelo formulário (botão ou tecla Enter)
- Marcar e desmarcar tarefas como concluídas
- Contador de tarefas pendentes

Os dados ficam apenas na memória: ao recarregar a página, a lista é zerada.
